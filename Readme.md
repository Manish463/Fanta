# Fanta — Creative Beverage Website

Fanta is a responsive, animation-focused frontend demo built with React. The project highlights smooth page transitions, micro-interactions, and responsive layouts to showcase a modern, animated landing experience for a beverage brand.

**Live Demo:** https://fanta-pi-nine.vercel.app/  
**Source Code:** https://github.com/Manish463/Fanta

## About

This is a frontend project focused on polished animations and responsive UI. It uses modern React patterns and animation libraries to create an engaging single-page experience.

## Tech Stack

- React
- Tailwind CSS
- Framer Motion
- React Icons

## Features

- Fully responsive layouts for mobile, tablet, and desktop.
- Entrance and scroll-triggered animations using Framer Motion.
- Interactive hover effects and animated banners.
- Responsive navigation and footer with accessible links.
- Lightweight, component-based React structure for easy customization.

## Quick Start

Prerequisites: Node.js (>= 16) and npm or yarn.

1. Clone the repo:

```bash
git clone https://github.com/Manish463/Fanta.git
cd Fanta/frontend
```

2. Install dependencies:

```bash
npm install
# or
yarn
```

3. Run the development server:

```bash
npm run dev
# or
yarn dev
```

Open `http://localhost:5173` (or the address printed by Vite) to view the site locally.

## Project Structure (brief)

- `frontend/src` — React source files
	- `components/` — UI components (Hero, Navbar, Banner, Blogs, FAQ, Footer, Products)
	- `assets/` — images and static media
	- `utils/` — small helpers (MouseFollower, SyncScroll)
- `frontend/public` — static files served by Vite
